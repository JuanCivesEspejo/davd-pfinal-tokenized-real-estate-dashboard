# EXPLORADOR DE INVERSIONES INMOBILIARIAS TOKENIZADAS

Aplicación web interactiva para explorar, comparar y analizar oportunidades de inversión inmobiliaria tokenizada mediante técnicas de visualización de datos y Machine Learning.

## Descripción del proyecto

La tokenización inmobiliaria permite a los inversores participar de forma fraccionada en proyectos de real estate, reduciendo la inversión mínima necesaria y facilitando el acceso a activos que tradicionalmente requerían un capital elevado.

Sin embargo, comparar correctamente distintas oportunidades de inversión puede resultar complejo. Cada proyecto presenta características diferentes en términos de rentabilidad esperada, duración, localización, tipo de inmueble, capital necesario, estrategia de inversión o estado del proyecto.

Además, fijarse únicamente en la rentabilidad anunciada puede ofrecer una visión incompleta. Un proyecto con mayor rentabilidad esperada puede implicar también un plazo más largo, encontrarse todavía en fase de desarrollo o presentar una mayor incertidumbre sobre su resultado final.

El objetivo de este proyecto es desarrollar una aplicación basada en datos que facilite la exploración y comparación de proyectos inmobiliarios tokenizados. La herramienta no pretende determinar automáticamente cuál es la mejor inversión, sino ayudar al usuario a comprender los diferentes perfiles de proyectos existentes.
